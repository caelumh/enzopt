# PINN 효소 표현 선택의 근거 (보완 인터뷰 2026-10-09 Q3: 준정상 채택 + 실패 기록)

결론: enzopt PINN은 효소 5형태를 **준정상 분포(5형태 고리의 King–Altman 해)**로 계산하고, 신경망은 실험마다 NADH(t) 하나만 표현한다. 방법론(CADKIMM `research/방법론_효소동역학_PINN.md` 4.2·4.3)의 원래 표현 — 효소 분율을 신경망 softmax 출력으로 두고 효소 식 잔차를 손실에 넣는 방식 — 은 현실적 합성 데이터에서 학습된 속도 상수가 데이터를 재현하지 못했다. 두 표현 모두 "효소의 ms 초기 과도층은 해상하지 않는다(혼합 사점 5 s ≫ ms)"는 같은 전제 위에 있다.

판정 기준: PINN이 낸 속도 상수로 ODE(scipy Radau)를 다시 풀었을 때 학습 세트(A·B)에 잡음 수준(σ = 0.003 A340)으로 맞는가. 표본은 결국 속도 상수이므로, 신경망 곡선이 데이터에 맞아도 ODE가 맞지 않으면 그 표본은 쓸 수 없다.

## 1. enzopt 안에서의 비교 (`comparison.csv`)

`uv run python scripts/compare_pinn_representation.py` — 예제 `projects/example_ldh_synth`(현실적 합성 데이터), 시드 4, Adam 2000 + L-BFGS 300, GPU float32, 사전분포 중심 = 문헌 자릿수.

| 표현 | 신경망 학습 RMSE | ODE 재해석 학습 RMSE (A / B) | K' (정답 23) | 해석 |
|---|---|---|---|---|
| `qss` 준정상 (채택) | 0.0041~0.0074 | 0.0041~0.0125 / 0.0066~0.0209 | 23.2~23.8 | 신경망과 ODE가 일치. 시드 3개는 3σ 안 |
| `full_gross` 원래 표현(총 플럭스 척도, 방법론 4.3) | 0.0035~0.0054 | 0.060~0.091 / 0.093~0.306 | 23.0~52.9 | 신경망은 데이터에 맞지만 ODE는 10~100배 어긋남 |
| `full_slow` 원래 표현(순 반응 속도 척도) | 0.011~0.033 | 0.017~0.125 / 0.024~0.085 | 20.3~22.4 | 물리식은 지키지만 학습이 수렴하지 않음 |

원인: 효소 식 잔차를 총 플럭스(순 플럭스의 약 100배)로 나누면 효소 분포가 크게 틀려도 벌점이 작다. 순 반응 속도로 나누면 문제가 (총/순)² ≈ 10⁴배 강성해져 경사 하강이 수렴하지 않는다. 준정상 표현은 효소 분포를 대수식으로 정해 이 강성을 없앤다(효소 식 잔차가 0).

## 논문에 적을 것

- 식별 모델: 완전 메커니즘(9종·10반응, Haldane, 보존 법칙 4개 내장)의 준정상 PINN. 신경망은 실험별 NADH(t), 물리 손실은 dNADH/dt = −r₁(준정상 효소 분포), 느린 잔차는 실험의 특성 속도 (hi−lo)/T로 정규화, w_phys는 1 → 10⁴로 올림.
- 대안 표현의 실패(위 표)를 방법 선택의 근거로 함께 보고한다.
- 정리 149의 자리는 그대로다: 반응식을 약가역 망으로 제한하는 구조 규칙과 사후 점검.
